4. Hybrid RAG Search & AI Solution Generation Sequence

Execution flow of Hybrid Dense + BM25 FTS5 Reciprocal Rank Fusion (RRF) search and streamed LaTeX solution generation.

sequenceDiagram
    autonumber
    actor Client as Web UI User (Browser)
    participant App as FastAPI App (src.api.app)
    participant Embedder as Embedder & Hybrid Engine (src.embedding)
    participant DB as SQLite DB (vector_index.db)
    participant Retriever as RAG Context Formatter (src.retrieval)
    participant LLM as Local Ollama / Cloud Gemini
    participant MathJax as MathJax Renderer (Frontend)

    Client->>App: POST /api/search { query, class_filter, subject_filter, type_filter }
    
    App->>Embedder: query_vector_store(query_text, filters)
    Embedder->>Embedder: Compute query dense embedding vector (384d)
    
    par Dense Vector Search
        Embedder->>DB: Scan dense embeddings & compute Cosine Similarity
        DB-->>Embedder: Dense Ranked Results (r_dense)
    and Sparse BM25 Keyword Search
        Embedder->>DB: Query FTS5 MATCH table
        DB-->>Embedder: Sparse Ranked Results (r_fts)
    end

    Embedder->>Embedder: Calculate RRF Score = 1/(60 + r_dense) + 1/(60 + r_fts)
    Embedder->>Embedder: Sort results by RRF Score
    Embedder-->>App: Top-K Hybrid Results with metadata & image links

    App->>App: Resolve static image URLs (/static/parsed/.../images/...)
    App->>App: Convert raw math notations to LaTeX via format_to_latex()
    App-->>Client: JSON Response (Question stems, LaTeX, options, diagrams)
    Client->>MathJax: Render dynamic LaTeX formulas & diagrams

    Client->>App: POST /api/explain { question_text, options, class_level, subject }
    App->>Retriever: format_rag_context(retrieved_chunks)
    Retriever-->>App: Grounded prompt context
    App->>LLM: POST /api/generate with Pedagogical Prompt
    LLM-->>App: Streamed Step-by-Step LaTeX Explanation
    App->>App: Sanitize LaTeX & PUA Font Glyphs
    App-->>Client: Final LaTeX Explanation & Correct Answer
    Client->>MathJax: Render Step-by-Step Solution on UI

5. Cross-Paper Deduplication Sequence Diagram

Computation of pairwise cosine similarity matrix across question vectors and one-click duplicate resolution.

sequenceDiagram
    autonumber
    actor Admin as Admin / Web UI
    participant API as FastAPI Backend (src.api.app)
    participant Dedup as Deduplication Engine (src.dedup)
    participant DB as Vector Store (vector_index.db)

    Admin->>API: GET /api/dedup (similarity_threshold = 0.85)
    API->>Dedup: find_duplicate_questions(threshold=0.85)
    Dedup->>DB: Fetch all embeddings (N, 384) & metadata
    DB-->>Dedup: Vectors matrix & metadata records
    
    Dedup->>Dedup: Compute Pairwise Cosine Similarity: S = V · V^T
    Dedup->>Dedup: Filter pairs where S[i,j] >= threshold AND papers/questions differ
    Dedup-->>API: List of duplicate pairs with diff preview & similarity score
    API-->>Admin: Render Duplicate Pairs in Web UI

    opt One-Click Duplicate Cleanup
        Admin->>API: POST /api/dedup/remove { chunk_id }
        API->>DB: DELETE FROM vectors WHERE id = chunk_id
        API->>DB: DELETE FROM vectors_fts WHERE id = chunk_id
        DB-->>API: Deletion confirmed
        API-->>Admin: { status: "success", deleted_chunk_id }
    end
